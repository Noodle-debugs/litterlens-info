Privacy policy

Effective October 2, 2026.

LitterLens Downloader is a personal automation for its owner's SiiPet account and Google Drive. It is not offered as a public service.

Information used

The tool uses SiiPet authorization credentials, device request headers, temporary AWS credentials, video object keys, event dates and identifiers, and Google authorization credentials. It downloads pet-camera MP4s and uploads them to the owner's Google Drive.

Google Drive access

The app requests the drive.file permission, allowing access only to files created by or explicitly used with this app. It reads folder and file metadata to organize videos and avoid duplicates, and creates folders and uploads videos. It does not sell Google user data or use it for advertising or training AI models.

Processing and storage

GitHub Actions processes the downloads. Credentials are stored in encrypted repository secrets, not in the public website or source code. Video files are held temporarily on the runner during transfer and stored in the owner's Google Drive. Drive metadata stores a video-key hash and event identifier for duplicate detection. Logs record dates, counts and sanitized errors rather than credentials or video contents.

Data is sent to SiiPet, AWS, Google and GitHub only as needed for authorization, downloads, uploads and operation. These providers apply their own privacy policies. This website is hosted by GitHub Pages, which may collect normal website access information.

Retention and control

Saved videos remain in Google Drive until the owner deletes them. Temporary download files are removed after processing. The owner can revoke Google access in Google Account connections, remove repository secrets and disable the workflow. Revoking access does not delete videos already saved.

Contact
